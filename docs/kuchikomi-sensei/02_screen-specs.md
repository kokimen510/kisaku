### 共通の振る舞い

- 選ばれている大項目は、青い背景＋白い文字＋「∧」。子メニューは縦の線でつなげて少し右にずらす。
- 画面幅が 1024px より狭いときは、サイドバーを隠してハンバーガーメニューにする【推定】。
- 「サポートに問い合わせる」は外部リンクのアイコン付き。公式LINEのURLを `target="_blank" rel="noopener"` で開く。

### 1-2. 押せる／押せないの条件

| ボタン | 押せる条件 |
|---|---|
| すべてのクチコミ返信を生成 | 未返信タブで、`status=UNREPLIED` かつ本文または評価があるカードが1件以上ある／生成中ではない |
| すべてを下書き保存 | 生成したが保存していない案（画面上の `isDirty=true`）が1件以上ある |
| 最新取得 | 取り込み中ではない（取り込み中はアイコンが回る）。続けて押せるのは30秒に1回まで |
| 言語の選択 | 「言語を指定する」にチェックが入っている |

### 1-3. クチコミカード【推定】

```
┌───────────────────────────────────────────────────────────────────────┐
│ (アイコン) 山田 太郎   ★★★★☆   2026/11/10        [Googleで見る↗] [返信不要] │
│ 店員さんの対応がとても丁寧で、ラテもおいしかったです。また行きます！       │
│ （英語のクチコミなら）▸ 日本語訳: ……                                     │
│ ─────────────────────────────────────────────────────────────────── │
│ 返信設定: スタッフ[基本設定] 文体[基本設定] 長さ[基本設定] 言語[基本設定] ▾  │
│ ┌───────────────────────────────────────────────────────────────────┐ │
│ │ 山田様、この度はご来店いただき誠にありがとうございます。…              │ │
│ └───────────────────────────────────────────────────────────────────┘ │
│ 182文字                       [↻ 再生成] [下書き保存] [返信する]          │
└───────────────────────────────────────────────────────────────────────┘
```

- 案がまだないときは、テキストエリアの代わりに `[✎ 返信案を生成]` を出す。
- 生成中はテキストエリアの上に読み込み中の表示を出し、ボタンを押せなくする。
- 「返信する」を押したら確認ダイアログ: `この内容でGoogleに返信を投稿します。よろしいですか？` [キャンセル] [投稿する]
- 投稿できたらお知らせ（トースト） `返信を投稿しました` を出し、カードを未返信タブから消す。
- 投稿に失敗したらカードに赤い文字で理由を出す（例: `Googleとの連携が切れています。設定から再連携してください`）。

### 1-4. まとめて生成の流れ

1. 押すと、対象のカードを上から順に **同時に3件まで** 生成する（上限を超えないため）。
2. 見出し行に進み具合を出す `生成中… 4 / 12`。途中で止める `[中止]` も出す。
3. 1件ごとにでき次第カードに入れる。失敗したものはカードにエラーと `[再試行]` を出し、ほかは続ける。
4. 終わったら `12件中11件の返信案を作りました（1件失敗）`。
5. まとめて生成したものは **自動で投稿しない**。保存するか、1件ずつ「返信する」を押すまでGoogleには出ない。

## 3. クチコミを集める【推定】

### 3-1. 店舗側：アンケート設定（`/collect/survey`）

- 左に設問の一覧（ドラッグで並べ替え）、右にスマホの見た目のプレビュー。
- 設問の型: 1つ選ぶ／いくつでも選ぶ／5段階／自由記述。
- 上に「QRコード」タブ: QR画像、URL、`[PNGで保存]` `[SVGで保存]` `[卓上POPをPDFで出す]`、設置場所を足すボタン。

### 3-2. お客様側：回答画面（`/s/{surveyToken}`、ログイン不要、スマホ用）

```
① ようこそ画面   店舗ロゴ・「ご来店ありがとうございます。30秒で終わるアンケートです」 [はじめる]
② 設問（1問ずつ） 例:「ご注文いただいたものは？」[ラテ][ケーキ][軽食]…
                   「良かった点は？」[味][接客][雰囲気][価格][清潔さ]
                   「満足度は？」★1〜5
                   「ひとことどうぞ（任意）」
③ 下書き画面     「いただいた回答から、クチコミの文を作りました。自由に直してください」
                   [テキストエリア（編集できる）] [↻ ほかの言い回し]
                   [📋 コピーしてGoogleに投稿する]  ← ★の数にかかわらず全員に出す
                   [投稿しないで終わる]
④ 感謝画面       「ご協力ありがとうございました」
```

- ③の主ボタンは **満足度が低い人にも同じように出す**（点数で分けない。07章）。
- 「コピーしてGoogleに投稿する」は、クリップボードに入れてから Google のクチコミ投稿URLを開く。iOS Safari でコピーが失敗したときは、本文を選択状態にして「長押しでコピーしてください」と出す。

## 4. 記事を投稿する（`/posts/new`）【推定】

| エリア | 中身 |
|---|---|
| 種類 | タブ: 最新情報／イベント／特典 |
| AI作成 | 「伝えたいこと」（例: 新メニューの栗のモンブラン、11/15から）＋キーワード → `[✎ AIで作る]` |
| 本文 | テキストエリア（1,500文字まで、文字数を表示） |
| 写真 | ドラッグで追加、1枚 |
| ボタン | 種類（なし／予約／注文／購入／詳細／登録／電話）＋URL |
| イベント・特典 | タイトル、開始・終了、クーポンコード、利用条件 |
| 投稿のタイミング | ◉今すぐ ○日時を決める |
| 右側 | Googleでの見え方のプレビュー |
| 下 | `[下書き保存]` `[投稿する／予約する]` |

## 5. 集客レポート（`/reports`）【推定】

- 上: 期間（今月／先月／過去3か月／自由に指定）と比べる相手（前の期間／前年）。
- 指標カード: 表示回数、ルート検索、電話、ウェブサイトのクリック。それぞれ前の期間と比べて ↑↓%。
- 折れ線グラフ: 日ごとの表示回数（検索・マップ／PC・スマホを積み上げ）。
- 表: 検索キーワードの上位20（キーワード、表示回数、前月比）。
- クチコミ: 件数・平均評価の推移、返信率、返信までの平均時間。

## 6. 設定（`/settings/*`）【推定】

| 子画面 | 中身 |
|---|---|
| Google連携 | 状態（連携中／切れている）、紐づけている店舗、`[再連携]` `[解除]` |
| 店舗情報 | 店舗名、業種、売り・特徴（3〜5個）、AIに伝えたいこと |
| スタッフ | 一覧＋追加ダイアログ（名前、役職、性別、一人称、署名、口ぐせ） |
| 返信ルール | 必ず入れる言葉、使わない言葉、署名の形、絵文字、低評価の方針 |
| 通知 | 新着・低評価・失敗 × メール／LINE のオンオフ |
