# 01. 機能一覧（細分化）

機能IDの付け方: `大分類-中分類-連番`。優先度は **P0**＝これがないと成り立たない／**P1**＝早めに必要／**P2**＝後回しでよい。

---

```
ダッシュボードを見る
クチコミを集める ∨      … QRコード/アンケート設定、回答一覧、店頭POP（推定）
クチコミに返信する ∧
  ├ 一覧                 … 確認

レガシー機能 ∨          … 旧バージョン画面への入口（推定）
```

## D. クチコミに返信する（`REP`）【確認：一覧画面】

### D-1. 返信の基本設定バー

| ID | 機能 | 詳細 | 優先度 | 確度 |
|---|---|---|---|---|
| REP-C-01 | 設定バーの説明文 | 「返信案に使う基本設定です。まとめて生成する前に必要な項目だけ調整してください。」 | P0 | 【確認】 |
| REP-C-02 | スタッフ選択 | 返信を書く人。初期値「未選択」。設定済みのスタッフ一覧から選ぶ。選ぶと署名や一人称に反映 | P0 | 【確認】 |
| REP-C-03 | 文体選択 | 初期値「フレンドリ」。選択肢の案: フレンドリ／丁寧／かしこまった／カジュアル | P0 | 【確認】（選択肢は【推定】） |
| REP-C-04 | 性別選択 | 書き手の性別。初期値「女性」。選択肢: 女性／男性／指定なし。言葉づかいに反映 | P0 | 【確認】 |
| REP-C-05 | 長さ選択 | 初期値「長文」。選択肢: 短文／中文／長文（文字数の目安は04章） | P0 | 【確認】 |
| REP-C-06 | 言語を指定する（チェック） | 初期はオフ。オンにすると「言語」選択が使えるようになる | P0 | 【確認】 |
| REP-C-07 | 言語選択 | オフのときは使えず「同じ言語で返信」と表示（＝クチコミと同じ言語で返す）。オンなら 日本語／英語／中国語(簡体)／中国語(繁体)／韓国語 などから選ぶ | P0 | 【確認】（選択肢は【推定】） |
| REP-C-08 | 基本設定の保存 | 歯車（COM-P-02）で店舗の既定値として保存。次に開いたときもその値になる | P1 | 【推定】 |

## E. 記事を投稿する（`PST`）【推定】

| PST-07 | 定期投稿 | 毎週◯曜など決まった日にAIで作って投稿（承認してから or 自動） | P2 |
| PST-08 | 投稿履歴 | 状態（予約中／投稿済み／失敗／却下）、閲覧数 | P1 |
