# クチコミ管理ツール 機能分解・再現仕様書

「クチコミ先生」（Googleビジネスプロフィール向けのクチコミ管理SaaS）の機能をすべて細かく分け、**同等の機能を自社で作り直せる粒度**で書いた仕様書です。

## 情報の出どころ（確度ラベル）

各機能には、どこまで確かな情報かを示すラベルを付けています。

| ラベル | 意味 |
|---|---|
| **【確認】** | 提供されたスクリーンショット（返信一覧画面）で目で見て確認したもの |
| **【公開】** | 公開されている導入事例・記事で確認したもの（卓上QR → アンケート → クチコミ化 の流れなど） |
| **【推定】** | メニュー名・業界の標準機能・Google API の仕様から推し量ったもの。実装の前に実物で確かめる |

> 実物を見られたのは「クチコミに返信 / 一覧」画面だけです。折りたたまれた他のメニューの中身は【推定】です。実物の画面キャプチャが追加で手に入れば、その分のラベルを【確認】に上げてください。

## 全体像（1枚で）

```
                ┌──────────────── 管理画面（店舗オーナー/スタッフ） ────────────────┐
                │ ダッシュボード │ クチコミを集める │ クチコミに返信 │ 記事投稿 │ 集客レポート │ 設定 │
                └───────┬───────────────┬──────────────┬──────────┬──────────┬─────────┘
                        │               │              │          │          │
 来店客 ──卓上QR──▶ アンケート ─AI─▶ クチコミ下書き ──▶ Googleマップに本人が投稿
                                        │              │          │          │
                                        ▼              ▼          ▼          ▼
                               ┌────────────────────────────────────────────────┐
                               │      Google Business Profile API               │
                               │ reviews / reply / localPosts / performance     │
                               └────────────────────────────────────────────────┘
```

**中心となる価値（再現するときの優先順）**

1. **返信を楽にする**：未返信のクチコミを取り込み → AIで返信案を作る（スタッフ・文体・性別・長さ・言語を指定）→ 直す → 下書き保存 → Googleに投稿
2. **クチコミを増やす**：卓上QR → アンケート → AIがクチコミ文の下書きを作る → お客様が自分で確認・編集してGoogleに投稿
3. **露出を増やす**：Googleの「最新情報」投稿をAIで作り、予約して投稿する
4. **効果を見せる**：表示回数・ルート検索・電話・検索キーワード・クチコミ件数と評価の推移をレポートにする
