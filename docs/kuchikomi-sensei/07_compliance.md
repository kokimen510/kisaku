# 07. 規約・法律への対応（必須要件）

「クチコミを集める」機能は、作り方を間違えると **Googleのポリシー違反（クチコミの削除・店舗プロフィールの停止）** や **ステマ規制（景品表示法）違反** になります。次の要件は、作り直すときに外してはいけない **P0** として扱ってください。

> 法的な最終判断は専門家に確認してください。ここに書いているのは、作るときの安全側の決まりです。

## 1. Googleのクチコミのポリシー

| # | 要件 | 理由 | 関係する機能 |
|---|---|---|---|
| C-01 | **満足度で分岐させない**。★1〜2の人にも★5の人にも、同じように「Googleに投稿する」ボタンを出す | 良い評価の人だけをGoogleに案内し、悪い評価の人を社内アンケートに流すこと（レビューゲーティング）は禁止されている | COL-S-03, COL-R-04 |
| C-02 | **下書きはお客様の回答だけから作る**。体験を足さない・大げさにしない | 事実と違う内容のクチコミは「虚偽のコンテンツ」にあたる | G2, AT-31, AT-32 |
| C-03 | **投稿するのはお客様本人**。店のアカウントや店の端末からまとめて投稿する機能は作らない | なりすまし・偽のクチコミは禁止 | COL-R-04 |
| C-04 | **見返りと引き換えにしない**。「クチコミを書いたら1品無料」などの特典とアンケート・投稿をつなげる機能は作らない | 見返りのあるクチコミの依頼は禁止 | COL 全体 |
| C-05 | お客様が下書きを自由に直せる・投稿しないことも選べる | 本人の意思で書いたものにする | COL-R-03, COL-R-05 |
| C-06 | 同じ端末からの連続回答を見分け、店舗側の画面で目印を付ける | 店員が自分で何度も回答していないかを見つけるため | survey_response.ua_hash |
| C-07 | 返信の自動投稿（SET-06）は初期オフ。オンにするときは対象を「★4〜5かつ本文なし」などに絞る | 低評価に機械的な返信が付くと炎上しやすい | SET-06 |

## 2. ステマ規制（景品表示法、2023年10月から）

| # | 要件 |
|---|---|
| C-08 | 店がお客様に頼んで書いてもらったクチコミでも、**見返り（値引き・特典・プレゼント）を出さない**限り、内容はお客様の自由な意見として扱える。見返りを出す仕組みは作らない（C-04 と同じ） |
| C-09 | 下書きに、店が言わせたい宣伝文句を混ぜない（「◯◯が地域No.1」など）。G2 のプロンプトで禁止している |
| C-10 | 店の関係者（スタッフ・家族）にアンケートを回答させない運用を、運用チェックリスト（COM-H-06）に入れる |

## 3. 個人情報

| # | 要件 |
|---|---|
| C-11 | アンケートでは名前・電話番号・メールアドレスを聞かない（必要なら任意にして、利用目的を書く） |
| C-12 | `ua_hash` は端末を見分けるためだけに使い、個人を特定できる形で持たない（ソルト付きハッシュ、90日で消す） |
| C-13 | 返信文に、クチコミに書かれた以上の個人情報（来店日時・予約名など）を書かない（G1 のプロンプトで禁止） |
| C-14 | Google の OAuth トークンは暗号化して保存し、連携を解除したらすぐに消す |
| C-15 | AIに送るデータ（クチコミ本文・回答）は、学習に使われない設定のAPIを使う |
