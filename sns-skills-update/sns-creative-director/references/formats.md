# 媒体別・構成テンプレート

同じネタでも媒体ごとに「言語」が違う。**1つのアイデアを媒体の言語に翻訳する**のが仕事であり、同じ文章を貼り回すのは仕事ではない。

---

## 1. カルーセル（Instagram / TikTok画像投稿 / X画像）10枚型

保存されるのは「あとで見返す価値」があるとき。**構造で読ませる。**

| # | 役割 | 中身 |
|---|---|---|
| 1 | フック | 表題（14字以内）＋ 損得を1行。実績数字があればここ |
| 2 | なぜ重要か | 読者が抱えている問題の言語化。「問題はここ」 |
| 3 | 中核の概念 | 概念を1つだけ。図解できる形にする |
| 4 | 分類・選択肢 | パターンを3〜5個。表かカード形式 |
| 5 | 差がつく点 | ここで勝つ、というポイント3〜5個 |
| 6 | 全体像 | 手順の一覧（ステージ図）。全体をひと目で |
| 7 | Step 1 | 具体手順。スクショ・画面例を入れる |
| 8 | Step 2 | 具体手順。人が判断する箇所を明示 |
| 9 | Step 3 | 具体手順。品質の担保方法 |
| 10 | 結論＋CTA | 3行に要約 ＋ 保存・フォロー・いいね ＋ 換金導線 |

ルール
- 1枚＝1メッセージ。表題は14字以内
- 枚数は7〜10枚（少なすぎると薄い、多すぎると離脱）
- 数字は必ず出典を明記（他人の実績は「元記事で報告されている実績」）
- 最終枚は必ず行動指示。ここを飾りにしない

---

## 2. ショート動画（TikTok / Reels / Shorts）30〜60秒型

離脱は最初の3秒と、中盤の「間」で起きる。**間を作らない。**

| 秒 | 役割 | 中身 |
|---|---|---|
| 0-3 | フック | 損得を言い切る。画面には14字テロップ。動きか変化を入れる |
| 3-8 | 前提 | 誰向けか・何の話か（1文）。「飲食店やってる人だけ」 |
| 8-20 | 本題① | 手順・事実・驚き。画面を必ず切り替える（3秒ルール） |
| 20-35 | 本題② | 具体例。実物・画面録画・数字を出す |
| 35-50 | 本題③ / 反証 | 「ただし◯◯だと効かない」で信頼を作る |
| 50-60 | 結論＋CTA | 1行結論 → 「保存して試して」「続きはプロフィール」 |

ルール
- カットは3秒以内で切り替える（同じ絵を4秒以上見せない）
- テロップは常時表示。音無しで意味が通ること
- 冒頭に「今日は解説します」を入れない（即・本題）
- ループ設計：最後の1文が最初の1文に繋がると再生が伸びる

---

## 3. Xスレッド

- 1ツイート＝全角140字以内（無料プラン準拠）。**URLは入れない**
- 1ツイート＝1論点。改行で「読める単位」に割る
- 1本目＝フック（数字＋損得）。2本目で前提、3〜5本目で手順、最後に一言誘導
- 誘導は「続きはプロフィールのnoteから」（URLを貼らない）
- 装飾記号・アスタリスクは使わない

---

## 4. Threads

- 220〜420字。専門レベルで書く（薄い汎用論は刺さらない）
- 構成：共感フック → 手法名＋なぜ効くか1行 → そのまま使える実務手順やプロンプト → 背中押し1行
- 専門用語を1つだけ正しく使う（例：FL率、メニューエンジニアリング、ABC分析）
- アスタリスク不使用。CTAは週2回程度に絞る

---

## 5. note記事（3000字・SEO）

| ブロック | 中身 |
|---|---|
| タイトル | 検索語＋ベネフィット＋数字。画像見出しは別に14字以内で用意する |
| リード（〜300字） | 誰の何を解決するか。**直後にCTA**（換金導線） |
| 本文① 問題 | 読者の現状と損失。具体的な場面で書く |
| 本文② 解決 | 手順を見出し付きで。コード・プロンプトはそのまま使える形で |
| 本文③ 具体例 | 実例・数字・失敗談。固有名詞を出す |
| 本文④ 反証 | 効かないケース。ここで信頼を得る |
| 結び | 3行要約 ＋ 問いかけ1つ ＋ **末尾CTA** |

---

## 6. YouTube（長尺）

- 冒頭15秒：結論＋この動画で得られるもの＋証拠（画面）
- 章立て：3〜5章。各章の頭に「これから何をするか」を1行
- サムネ文字は9字以内・2行まで。タイトルと同じことを書かない
- 終盤で次の動画へ橋渡し（1本で完結させない）

---

## 7. 横展開マトリクス（1ネタ→複数媒体）

| 元ネタ | 展開先 | 変換方法 |
|---|---|---|
| note記事 | Xスレッド | 見出しを1論点1ツイートに圧縮 |
| note記事 | カルーセル | 手順を1枚1ステップの図に |
| ショート動画 | Threads | 台本のナレーションを実務手順として書き直す |
| 海外記事・英語ポスト | note＋カルーセル | 日本語圏の文脈（日本の店・日本の制度）に翻訳して価値を足す |
| YouTube | ショート | 最も驚きのある30秒を切り出し、冒頭にフックを付け直す |
