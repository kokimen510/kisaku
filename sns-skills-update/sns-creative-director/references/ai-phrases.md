# AIっぽさ辞書（humanizer段で使う）

humanizer の段で、原稿をこの辞書に当てて **決まり文句と記号の跡を0件** にする。
目分量で「たぶん大丈夫」で済ませない。1語ずつ探す。

出典: instagram-agent-skill-ja（Alman-creator-uslog・MIT License）の `slop.json` から、
店舗PR・SNS投稿で出やすいものを抜き出して整理した。原典は英語版 instagram-agent-skill（Jake Schincariol・MIT）。

---

## 1. 自動で置き換えてよいもの（意味が変わらない）

日本語は活用で形が変わるので、1語ではなく「文が壊れない単位」で置き換える。

### 硬い言い回し
| 探す | 置き換え |
|---|---|
| することができ | でき |
| することが可能です／可能な | できます／できる |
| において／における | で／の |
| に関して／に関する | について／についての |
| に基づいて／に基づく | をもとに／をもとにした |
| という観点から | の面から |
| であると言えるでしょう／だと言えます | です |
| と考えられます | と思います |
| 非常に／極めて | かなり（または削る） |
| 重要なのは／重要です／重要な | 大事なのは／大事です／大事な |
| 必要不可欠／不可欠な | 欠かせない |
| さまざまな／様々な／多種多様な | いろんな（できれば具体名に） |
| 多岐にわたる | 幅広い |
| 数多くの | たくさんの（できれば数字に） |
| 新たな／新たに | 新しい／新しく |
| 迅速に | すぐに |
| 最大限に／最大限の | 目いっぱい／目いっぱいの |

### 定番の動詞
| 探す | 置き換え |
|---|---|
| を活用して／を活用する／を活用することで | を使って／を使う／を使うことで |
| を利用して／を使用して | を使って |
| を促進する | を進める |
| を向上させる | を上げる |
| を構築する | を作る |
| に寄与する | に役立つ |
| を把握する | をつかむ |
| を検討する | を考える |
| 重要な役割を果たす | 大事な役目がある |
| 鍵となる／鍵を握る | 決め手になる |
| 可能性を秘めた | 見込みのある |

### カタカナ語・大げさ
| 探す | 置き換え |
|---|---|
| シームレスに／シームレスな | スムーズに／スムーズな |
| ゲームチェンジャー／パラダイムシフト | 大きな変化 |
| シナジー | 相乗効果 |
| ソリューション | 解決策 |
| ポテンシャル | 可能性 |
| ベストプラクティス | うまいやり方 |
| 革新的な／画期的な | 新しい（できれば何が新しいかを書く） |
| 包括的な／網羅的な | まとまった |
| 完全ガイド／徹底解説／完全解説 | ガイド／解説 |
| の秘訣／の極意 | のコツ |

### 消すだけの前置き・締め
- 前置き：「現代社会において、」「現代において、」「昨今、」「本記事では、」「この記事では、」
- 動画の前置き：「この動画では、」「今日の動画では、」「今回の動画では、」
- 注目のお願い：「スクロールしないで」「スクロールする手を止めて」「最後まで見てね」「最後まで見逃さないで」
- 反射のお願い：「いいねとフォローお願いします」「いいね・保存お願いします」「最後まで見てくれてありがとう」
- 作文の締め：「いかがでしたか」「いかがでしたでしょうか」「参考になれば幸いです」「ぜひ参考にしてみてください」「最後まで読んでいただきありがとうございました」
- 弱める：「ぜひ試してみてください」→「試してみてください」、「〜てみてはいかがでしょうか」→「〜てみてください」

## 2. 記号の跡（全部直す）

| 記号 | 直し方 |
|---|---|
| 長いダッシュ（— ―） | 「、」に。文の終わりの直後なら「。」 |
| 数字の間の短いダッシュ（10-20） | 「〜」に（10〜20） |
| 英語のかぎ（“ ”） | 「」に |
| 黒丸（•） | 「・」に |
| マークダウン（** ## など） | 消す。Instagram・Xでは記号のまま出る |
| アスタリスク（*） | 消す（既存ルール） |
| 見えない文字（幅ゼロの空白・BOM・ソフトハイフン・改行しない空白など） | 消す。コピペで紛れ込み、どのエディタでも見えない |
| 全角「＃」のハッシュタグ | 半角「#」に（全角はタグにならない） |

**残すもの**：三点リーダー（…）、矢印（→）、全角スペース、組み合わせ絵文字（家族の絵文字など）。日本語ではふつうに使う。

## 3. 文の形の跡（機械的に消さない・1文ずつ手で書き直す）

形を変えるには判断が要る。見つけたら意味を残して書き直す。

| 形 | 直し方の方向 |
|---|---|
| 「〜だけでなく、〜も」「単なる〜ではなく」 | 言いたい方だけを言い切る |
| 「大切なのは〜ではなく〜」 | 結論だけを先に言う |
| 3つ並べ（「A、B、そしてC」「ポイントは3つ」） | 本当に3つか。2つなら2つ、1つなら1つ |
| 1行だけの問いかけ（「その結果は？」） | 答えから書く |
| 「学んだことをシェアします」 | 学んだことそのものから始める |
| 「〜ではないでしょうか」 | 言い切る |
| 「〜しましょう！」の連発 | 1投稿に1回まで |
| 「まとめると」「要するに」「結論として」で始まる締め | 消して結論の文だけ残す |
| 「どう思いますか？」「共感した人はいいね」 | 具体的な行動のお願い1つに替える |
| 「〜とは？」の見出し | 1文で説明する |
| 同じ文末が3回以上続く | 言い切り・体言止め・問いかけを混ぜる |
| 文の長さがそろいすぎ | 短い文を1つ挟む |
| 🚀🔥💡✨🎯 の絵文字、絵文字の箇条書き | 絵文字は1つまで。箇条書きは「・」か改行 |
| ハッシュタグの壁（5個以上を連ねる） | 3〜5個に絞る |

---

## 4. 削ってはいけないもの

- **口語・方言**（「〜やねん」「〜して」「えぐい」）：人の声。store-pr-telop の熱の源なので残す
- **具体的な行動のお願い**（「保存して明日の会議で試して」「予約はプロフィールから」）：決まり文句ではない
- **本人がいつも使う言い回し**：この辞書に載っていても本人の口ぐせなら残し、辞書側から外す

## 5. 短い文の判定

コメント・DM・テロップのような短い文は、数字が無くても問題ない。
「決まり文句0件」「記号の跡0件」だけで判定する。数字を作ったり文を足したりしてまで具体性を上げない。
