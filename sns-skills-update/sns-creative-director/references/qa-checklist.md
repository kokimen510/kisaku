# 出荷前検品（1つでもNGなら出荷しない）

## A. フック・構成

- [ ] 最初の3秒（1枚目）で損得を提示しているか
- [ ] 主語が読者になっているか（自己紹介・挨拶から始めていないか）
- [ ] 1画面＝1メッセージを守っているか
- [ ] 見出し・表題は14字以内か
- [ ] 削れる文が1つも残っていないか

## B. AIっぽさの除去

削る語・型
- 「〜していきましょう」「重要なのは」「まとめると」「いかがでしたか」
- 「〜と言えるでしょう」「〜ではないでしょうか」
- 過剰な箇条書き（3階層以上のネスト）
- em-dash（—）の多用、意味のない絵文字
- 抽象語の羅列（本質・マインド・大切なこと・価値提供）

足す要素
- 一人称（僕は／実際にやってみて）
- 固有名詞（店名・地名・ツール名・数字）
- 失敗談・迷った理由
- 断定と留保の使い分け（「効きます」だけでなく「◯◯の店では効きません」）

チェック
- [ ] コピペ用テキストに **アスタリスク（*）** が入っていないか
- [ ] 定型句を全て削ったか
- [ ] 具体（数字・固有名詞）が最低3箇所あるか
- [ ] `ai-phrases.md` の決まり文句が0件か（「することができ」「において」「さまざまな」「この動画では、」など）
- [ ] 記号の跡が0件か：長いダッシュ（— ―）、マークダウン（** や ##）、英語のかぎ（“”）、見えない文字（幅ゼロの空白・BOMなど）。三点リーダー（…）と矢印（→）は残してよい
- [ ] 同じ文末が3回以上続いていないか（「〜ます。〜ます。〜ます。」）。言い切り・体言止め・問いかけを混ぜる
- [ ] 文の形の跡（「〜だけでなく〜も」「大切なのは〜ではなく」「ポイントは3つ」「〜ではないでしょうか」）は機械的に消さず、意味を残して1文ずつ手で書き直したか
- [ ] 口語・方言（「〜やねん」など）は人の声なので、AIっぽさとして削っていないか

## C. 事実・数値

- [ ] 数値は実測か（推定なら「推定」と明記）
- [ ] 他人の実績を引く場合、「元記事で報告されている実績」と出典を明記したか
- [ ] 未確認の情報に「未確認」と書いたか
- [ ] 引用元の主張を自分の主張として書いていないか

## D. 換金導線（CTA）

- [ ] リード直後と末尾の2箇所にCTAがあるか
- [ ] CTAは1つに絞られているか（複数並べると全部押されない）
- [ ] 行動が具体か（「チェックしてね」ではなく「保存して明日の会議で試す」）
- [ ] Instagramのキャプション本文にURLを貼っていないか（押せない。プロフィール・DMへ）
- [ ] 投稿文にハッシュタグが入っていないか（全媒体で付けない）

## E. 法務スキャン

- [ ] 薬機法：健康・効果効能の断定表現がないか（「治る」「痩せる」「免疫が上がる」）
- [ ] 景表法：最上級・No.1・「日本一」の無根拠表示がないか。産地・ブランド表示の基準を満たすか
- [ ] ステマ規制：提供・タイアップがある場合、PR表記があるか
- [ ] 著作権：他人の画像・動画・文章の無断転載がないか（引用は出典と主従関係を守る）
- 懸念があればCLO（法務）に確認してから出す

## F. ビジュアル

- [ ] 文字と背景のコントラストが十分か（小さい画面で読めるか）
- [ ] 整列（余白・行間・要素の位置）が揃っているか
- [ ] 意味のない装飾（グラデ・幾何・ストック感）を削ったか
- [ ] 画像は正規スクリプトの復元実行か（作り直し・簡略版は差し戻し）
- [ ] 音無しで意味が通るか（テロップだけで理解できるか）
- [ ] テロップが縦画面の安全な枠内か（上230px・1440pxより下・右230pxを避ける）。フックが最初のコマから出ているか

## G. 学習ログ（投稿後・翌朝）

3行で残す：
1. 最弱の1指標（例：保存率が低い）。比べるのは再生数ではなく伸び倍率（再生数 ÷ 直近投稿の再生数の中央値）とリーチあたりのシェア・保存数
2. 伸びた要素（フック／テーマ／尺／時間帯のどれか）
3. 明日変える1施策（1つだけ。複数変えると何が効いたか分からない）

勝った型は翌週に横展開して量を増やす。負けた型は静かに止める。
