# 台本・テロップ・キャプション

## 1. 台本フォーマット（そのまま撮影・編集に渡せる形）

```
【タイトル】（内部管理用）
【尺】45秒 / 【媒体】TikTok・Reels / 【狙い】飲食店オーナーに「原価計算をAIに投げる」を試させる

| #  | 時間      | テロップ（14字以内） | ナレーション（話す言葉）                     | 画面・素材        | SE/BGM |
|----|-----------|----------------------|----------------------------------------------|-------------------|--------|
| 1  | 0:00-0:03 | 原価、勘でやってない？ | 原価、いまだに勘でやってませんか。            | 手書き伝票のアップ | ポンッ |
| 2  | 0:03-0:08 | 9割が損してます       | 実はここ、9割の店が取りこぼしてます。          | 話者バストアップ   | -      |
| 3  | 0:08-0:20 | 30秒で出せます        | やることは、この3行を貼るだけです。            | 画面録画（入力）   | タイプ音 |
...
【CTA】保存して、明日のメニュー会議で試してみてください。
```

必須列：時間 / テロップ / ナレーション / 画面 の4つ。SE・BGMは任意。

## 2. 秒割りの原則

- カットは3秒以内で切り替える。同じ絵を4秒以上見せない
- 1カット＝1メッセージ。2つ言いたいならカットを割る
- 「間」を作らない。息継ぎは編集で詰める
- 話速は1分＝300〜350字が目安。60秒動画のナレーションは300字前後に収める
- 1行ごとの秒数は「かなに直した音の数 ÷ 9」で見積もる（カット編集後は ÷10）。フック行が3秒、1カットが4秒を超えたら割る
- 本人に一度台本を声に出して読んでもらい、実測の秒数があればそちらを優先する（話す速さは人で違う）
- 最後の1文が冒頭に繋がるとループして再生数が伸びる

## 3. テロップ規則

- **1画面＝1メッセージ**。14字以内（既存ルール）。超えるなら画面を分ける
- 話し言葉をそのまま切らない。**読める単位で改行**する
  - 悪い例：「原価計算を/AIに投げるだけで/かなり時短に/なります」
  - 良い例：「原価計算はAIに投げる」→ 次の画面「時短は1日30分」
- 体言止めを混ぜてリズムを作る（全文が「です・ます」だと眠くなる）
- 数字・固有名詞・具体物を必ず1つ入れる（「多くの店」ではなく「加古川の焼肉店」）
- 強調は色1色まで。3色以上使わない
- 可読性：文字と背景のコントラストを確保。半透明の帯を敷く
- 意味のない装飾（グラデ・幾何・過剰な絵文字）は削る
- 音無しで意味が通ること（無音視聴が前提）
- フックのテロップは **最初のコマから** 出す（無音の間の後ではない）
- **安全な枠に置く**（1080×1920の縦画面）：上端から230pxより上、1440pxより下、右端230pxには置かない。そこはキャプション・右の操作ボタン・音源表示が重なって読めない。特にフックを画面下に置かない

## 4. キャプション（媒体別）

| 媒体 | 長さ | 書き方 |
|---|---|---|
| TikTok | 1〜2行 | 動画の続きを補足しない。1行フック。ハッシュタグは付けない |
| Instagram | 冒頭2行が勝負 | 2行目までに損得。以降は手順。末尾に保存を促す1行（詳細は下の「Instagramキャプションの細則」） |
| X | 全角140字以内 | URLを入れない。1論点。改行を使う |
| Threads | 220〜420字 | 専門レベル。実務手順を渡す |
| YouTube | 3行＋章立て | 冒頭3行に結論。タイムスタンプを付ける |

**投稿文にハッシュタグは付けない（全媒体共通）。** 探されている言葉は、タグではなく本文の文中に入れる。

### Instagramキャプションの細則

- **見える量**：フィードで「…続きを読む」の前に見えるのは、ユーザー名込みで2行＝全角30字前後（機種・文字サイズで変わる。一度実機で確認する）。リール画面では1行ほど
- **役割を先に決める**
  - 役割A（リール）：動画がもうフックを持っている。キャプションは2つ目のフックで張り合わず、1行目に行動のお願い・その説明・検索される言葉
  - 役割B（写真1枚・カルーセル）：キャプションが中身。1行目がフック。文の途中ではなく「続きが気になる所」で切れるように書く
- **検索される言葉は文の中に**：Instagram検索はキャプション本文を読む。タグは付けず、3行目の文中に「高槻の居酒屋」と人が打つままの言葉で入れる。2〜3語を決めてから書く
- **ハッシュタグは付けない**
- **キャプションにURLを貼らない**（押せない）。プロフィールかDMへ誘導する
- **お願いは1つ**（保存・合言葉コメント・DM・予約のどれか）。合言葉は短く変換で迷わない言葉にし、動画内でも声に出す
- 長さは2,200字が上限だが、押してもらえる600字のほうが強い
- カルーセル・写真には代替テキストを書く

## 5. 3段ループ（原稿の磨き方・必ず1周）

1. **writer**：構成に沿って書き切る（質より完成）
2. **humanizer**：AIっぽさを削る。一人称・具体・固有名詞・失敗談を足す。定型句（〜していきましょう／重要なのは／まとめると）を全部消す
3. **critic**：3点で批評し、直す
   - フック：3秒で損得が出ているか
   - 正確さ：数値は実測か。出典は明記されているか
   - 簡潔さ：削れる文が1つも無いか（削って意味が変わらない語は全部削る）

criticを通っていない原稿は提出しない。
