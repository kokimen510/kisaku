# フック設計（最初の3秒がすべて）

フックの仕事は1つだけ。**「この先を見ないと損をする」と3秒で思わせること。**
情報量を詰めるのではなく、1つの緊張（ギャップ・矛盾・損失）を作る。

## 判定基準（3秒テスト）

- [ ] 主語が「あなた（読者）」になっているか（自分語りで始めていないか）
- [ ] 損得・驚き・矛盾のどれかが入っているか
- [ ] 14字以内で言い切れているか（テロップ化できるか）
- [ ] 数字・固有名詞・具体物が1つ入っているか
- [ ] 続きを見なくても満足してしまう「言い切り」になっていないか
- [ ] 声に出して3秒以内に言い終わるか（かなに直して約27音以内。1秒に約9音で計算）
- [ ] 1文字目から中身か（あいさつ・前置き・「ちょっと待って」に1秒も使っていないか）

## フック30型

### A. 損失回避（最も強い）
1. 知らないと損する系：「これ知らずに◯◯してる人、月◯万損してます」
2. 手遅れ系：「気づいた時にはもう遅い、◯◯のサイン」
3. 全員間違えてる系：「9割の人がここを間違えてます」
4. やってはいけない系：「◯◯だけは絶対にやらないでください」
5. 落とし穴系：「無料でやると、あとで請求されるもの」

### B. ギャップ・意外性
6. 逆張り：「毎日投稿、実はやめた方がいい」
7. 常識否定：「◯◯は要りません。必要なのは1つだけ」
8. 権威の裏切り：「プロほど使わない道具」
9. Before/After：「3ヶ月前まで0円でした」
10. 数字のギャップ：「作業10分。売上は変わらないどころか増えた」

### C. 具体・実績（数字は必ず実測）
11. 実績提示：「◯◯回再生。やったのはこれだけ」
12. プロセス公開：「これ、実際の画面です」
13. 失敗談：「30万円溶かして学んだこと」
14. 検証：「1ヶ月やってみた結果」
15. 比較：「AとB、どっちが速いか測りました」

### D. 好奇心・未完
16. リスト予告：「◯◯する5つの方法。3つ目が本命」
17. 秘密：「言いたくないけど、これが全部です」
18. 質問：「なぜこの店だけ、平日も満席なのか」
19. 断片提示：「この1行を足すだけで変わります」
20. 名前当て：「これ、名前がついてます」

### E. 共感・自己投影
21. あるある：「これ、やってる人多いです」
22. 悩み代弁：「時間はあるのに、進まない」
23. 過去の自分：「1年前の自分に見せたい」
24. 属性指定：「飲食店やってる人だけ見てください」
25. 味方宣言：「センスが無くても大丈夫です」

### F. 権威・新規性
26. 新機能・最新：「先週出た機能、もう使ってますか」
27. 海外先取り：「アメリカでは既に当たり前です」
28. 引用：「◯◯がこう言ってました」
29. 独自命名：「僕はこれを◯◯と呼んでます」
30. 手順の言い切り：「やることは3つだけです」

## NGフック（即やり直し）

- 「今日は◯◯について解説します」（自己紹介・予告だけ）
- 「皆さんこんにちは」（挨拶から始める）
- 「重要なのは◯◯です」「まとめると」（AIっぽい定型）
- 「〜していきましょう」（他人事の号令）
- 抽象語だけ（「本質」「マインド」「大切なこと」）
- 誇張・煽り（「絶対」「必ず」「人生変わる」）— 信用を削る
- 注目をお願いする出だし（「ちょっと待って」「スクロールしないで」「最後まで見て」）— 頼む時点で掴めていない
- フックに絵文字（🔥✨など）— 14字のテロップに言葉と絵文字の両方を置く場所はない

## 3案の出し方

- 3案は **違う型から1つずつ** 出す（A〜Fの別グループが理想）。同じ型の言い換え3つは1案と同じ
- 各案は「話す1行」と「テロップ（14字以内）」を分けて書く。声と文字は役割が違う
- 数字が要るのに本人から数字をもらっていなければ、作らずに `{{要確認:金額}}` のように穴のまま残して知らせる

## フックの直し方（弱いと感じたら）

1. 主語を読者に変える
2. 数字か固有名詞を1つ入れる
3. 「得」ではなく「損」で言い直す
4. 14字に削る（削れないなら論点が2つある）
5. 続きを見たくなる「未完」を残す
