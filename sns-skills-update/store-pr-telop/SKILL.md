# 店舗PR動画 テロップ生成

縦型SNS動画（TikTok / Instagramリール / YouTubeショート、15〜30秒）で「スクロールを止めて最後まで見せ、来店・注文につなげる」テロップを設計する。

**このスキルは汎用。特定の店舗に紐づかない。** 飲食・カフェ・物販・サービス業を問わず、毎回違う店舗を扱う前提で動く。過去に別の店舗を扱っていても、その情報を新しい店舗に流用しない。

---

## 手順

### STEP 0: 対象店舗を特定して情報を揃える

**「テロップ作って」だけ言われた場合、どの店舗の何の動画かは分からない。必ず最初に確認する。**

以下が会話から埋まっているか確認し、**足りない項目は AskUserQuestion で一度にまとめて聞く。全部揃うまで生成しない。**

必須（これがないと成立しない）:
- 店名 / 業種 / 立地
- ターゲット層
- **この店にしかない一番の武器**（他店が言えない事実を1つ）
- 今回の主役（店舗全体 / 特定商品）
- 現在の時季

あると精度が上がる:
- 看板商品2〜3個 / 価格（裏取り済みの数字のみ）
- 品質表示の可否（「和牛」「国産」等を名乗れる根拠があるか）
- 予約・導線（電話 / SNSアカウント / テイクアウト可否）
- 尺（無指定は15秒）/ 視点（無指定は店舗目線）
- 地域の言葉（関西弁OK 等）
- 使える撮影済みカット
- 過去に作った動画の切り口（被り回避）

**同一会話内で同じ店舗の2本目以降**を作るときだけ、STEP 0 を省略して前回の情報を引き継ぐ。店舗が変わったら必ず聞き直す。

## 設計原則（生成時に必ず守る）

### 1. フック先行 — 最重要
動画の成否は最初の2秒で8割決まる。まず「引き」を設計し、それ以外は後回し。

**0秒に置くのは商品名でも店名でもない。** 思わず指を止める一言。優先順位:

1. 体感・感情の代弁 —「この暑さ、これで生き返る」
2. 数字の異常値 —「3時間飲んで食って4,500円」
3. 常識への疑問・否定 —「これ、飲み物に見えます？」
4. 当事者の名指し —「梅田で店決められん幹事へ」
5. 置いていかれ感 —「まだこれ食べてないの？」

商品名・店名は後半〜締めで出す。先に出すと「宣伝」と判断され離脱される。

**フックのNG（0秒に置かない）**
- あいさつ・前置き（「どうも〜」「今日は◯◯を紹介します」）
- 注目のお願い（「ちょっと待って」「スクロールしないで」「最後まで見て」）
- 絵文字（テロップの場所を食う）

**フック案は違う切り口から出す。** 下の切り口カタログの別々の行から選ぶ。同じ切り口の言い換えを並べない。
ナレーションを入れる場合、フックの1行は声に出して3秒以内（かなで約27音以内）。

### 2. 情報の順番（黄金の流れ）
```
フック（引っかける） → 正体（何なのか） → 証明（なぜ良いか・シズル）
→ 付加価値 → 締め（店名・価格・予約導線）
```
価格や商品名はできるだけ後ろへ。先に見せると驚きが減る。

### 3. テロップの物理ルール
- 1画面1メッセージ。2つの情報を1画面に詰めない
- 1行は全角14字以内。スマホの縮小表示で読めることが最優先
- 強調は【】か改行で**1語だけ**立てる。全部強調は無強調と同じ
- 2〜3秒ごとに切り替える。1枚を長く出さない
- フックのテロップは最初のコマから出す。無音の間を置かない
- 安全な枠に置く（1080×1920）：上230pxより上・1440pxより下・右230pxには置かない。キャプションや右の操作ボタンが重なって読めない
- 締め直前の1行でフックの言葉を1つ繰り返すと、2周目の再生につながる（ループ）。締め固定テロップの邪魔にならない範囲で

### 4. 声・トーン
- 一人称・話し言葉。「〜です」より「〜やねん」「〜して」等、口語の熱を優先
- 地域に合わせて方言を混ぜる（当事者感が出る）
- ターゲット層の言葉を使う（10〜20代女性なら「優勝」「無理」「えぐい」等も可。ただし多用しない）

### 5. 主語の統一
- **店舗目線**（デフォルト）: 主語は必ず店側。「うちが出す」「うちに来て」「うちの自信作」。第三者の紹介口調にしない
- **クリエイター目線**: 来店客・発見者の視点で書く

### 6. 季節・時季
- 旬のフックを優先。特に「終わりかけの季節」は締め切り効果が最も強い（「この夏、まだこれ食べてないの？」）
- ただし季節ワードは、その季節を過ぎると動画が「季節外れ」に見える
- 長期間回すなら季節ワードを避け、短期集中で今バズらせたい場合のみ全面に出す
- **この判断が要る場合は、季節あり／なしの両案を出して選ばせる**

## 法令・誇張ルール（違反は店舗を危険にさらす。例外なし）

**景品表示法**
- 裏付けのない最上級・断定は使わない:「日本一」「No.1」「最安」「絶対」は根拠資料がない限り不可
- 「和牛」「国産」「オーガニック」等の品質表示は、事実確認が取れた場合のみ。取れなければ「名物」「厚切り」等に言い換えを提案
- 数値（価格・品数・時間・割引）は「撮影時点の実際の提供内容と一致させること」を必ず注記
- 店舗から数字をもらっていない場合は作らない。仮置きもしない。テロップに `{{要確認:価格}}` のように穴のまま残し、確認事項に挙げる

**リピート・人気訴求は数値を避け、行動描写で表現する**
- ✕「リピート率90%」→ ○「気づいたら、また頼んでる」「二杯目が早い」「空になったカップ」
- 行動描写は裏取り不要で同じ説得力が出る

**薬機法**
- 健康・効果効能の断定（「痩せる」「治る」「デトックス」）は使わない

**PR表記**
- 店舗自身の投稿なら不要。外部クリエイターのタイアップなら冒頭と概要欄にPR表記を促す

## 出力フォーマット（この構成を必ず守る）

```
■ フック案（0〜2秒）
強い順に3〜5案。案の羅列に徹する（各案に理由を添えない）

■ 通しテロップ案
| 秒 | テロップ | 映す画 |
の3列。尺は指定に従う（無指定は15秒）

■ 入り2秒の別案
3案

■ 締め固定テロップ
店名・価格・アクセス・予約/SNS導線

■ 設計の狙い
2〜3点だけ。なぜその順番・言葉にしたかを短く

■ 確認事項
裏取りが要る数値・表記、不足している素材
```

推奨案を1つ明示する。ただし断定せず、選択の余地を残す。

## 切り口カタログ

| 切り口 | 0秒に置くもの | 効く場面 | 例 |
|---|---|---|---|
| 価格の異常値 | 数字 | 安さ・量が武器 | 3時間飲んで食って4,500円 |
| 見た目ギャップ | 色・形の驚き | 映える商品 | これ、飲み物に見えます？ |
| 味ギャップ回収 | 「合うわけない」 | 意外な組み合わせ | 合うわけないと思ってました |
| 季節・締め切り | 時季の焦り | 旬・期間限定 | まだこれ食べてないの？ |
| リピート訴求 | 中毒・戻ってくる | 常連が多い店 | 気づいたら、また頼んでる |
| 希少・トレンド | 韓国・行列・限定 | 話題性のある店 | ソウルで並ぶやつ、大阪きてます |
| 当事者名指し | 「〇〇な人へ」 | 客層が明確 | 梅田で店決められん幹事へ |
| 告白・本音 | 店の内情の吐露 | 価格・こだわり訴求 | 正直これ、赤字です… |
| 気づいて系 | 「まだ知らんの？」 | 既に人気・置いてかれ感 | ここ、これ気づいてる？ |
| 無言シズル | 音・結露・湯気 | 質感が武器の商品 | （テロップ最小・音で魅せる） |

## 出力前の自己チェック（全項目クリアするまで出さない）

- [ ] 対象店舗の情報を、この会話で確認したものだけで組んでいるか（別店舗の情報を混ぜていないか）
- [ ] 0秒が、商品名でも店名でもなく「引っかかる一言」になっているか
- [ ] フック案が別々の切り口から出ているか。あいさつ・「ちょっと待って」・絵文字で始まっていないか
- [ ] 順番が フック→正体→証明→付加価値→締め になっているか
- [ ] 1画面1メッセージ・1行14字以内を守れているか
- [ ] テロップの置き場所が安全な枠内か（画面下・右端に置いていないか）
- [ ] AIっぽい定型（「〜することができ」「さまざまな」「いかがでしたか」、長いダッシュ、** などの記号）が0件か
- [ ] 指定された視点（店舗/クリエイター）で主語が統一されているか
- [ ] 時季に合ったフックか。季節外れリスクがあるなら両案を出したか
- [ ] 最上級・品質表示・数値に裏取りの注記を付けたか
- [ ] リピート訴求を数値ではなく行動描写で表現したか
- [ ] 締めに店名・アクセス・予約/SNS導線が入っているか
- [ ] 確認事項（不足素材・要裏取り数値）を列挙したか

---

## やらないこと

- 店舗情報を確認せずに、推測やテンプレでテロップを作り始めない
- 前に扱った別の店舗の武器・価格・導線を流用しない
- フックを付けずに商品説明から始めない
- 1画面に情報を詰め込まない
- 裏取りできない誇張・最上級表現を出さない
- 季節外れリスクを黙って季節ワードを入れない
- 指定された視点（店舗/クリエイター）を無視しない
